## 核心思想
双重循环 `for j: for i < j` 里，内层其实是在问“`j` 左边有没有/有多少个满足条件的 `i`”。
把左边已经遍历过的信息**边走边存**进哈希表（或一个变量），内层循环就变成 O(1) 查询。

## 模板
```python
def count_pairs(nums):
    seen = {}                       # 左边出现过的信息：值 -> 次数 / 下标 / 最值……
    ans = 0
    for j, x in enumerate(nums):
        ans += seen.get(need(x), 0) # 1. 先用左边的信息回答以 j 为右端的问题
        seen[x] = seen.get(x, 0) + 1  # 2. 再把 j 加入“左边”
    return ans
```
**先查后存**，保证只统计 `i < j`，也不会让元素和自己配对。

## 和前缀和结合（560）
子数组和 `sum(nums[i:j]) == k` ⇔ `s[j] - s[i] == k`。对前缀和数组做“枚举右维护左”，
`seen` 里要预先放入 `s[0] = 0` 出现 1 次。

## 易错点
- 需要的是“最近的下标”（219）时，存下标并直接覆盖；需要的是“个数”时，存次数。
- 维护的不一定是哈希表：121 只需要维护“左边的最小值”这一个变量。
