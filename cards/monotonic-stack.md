## 核心思想
栈里只保留“还有可能成为某个后续元素答案”的下标。新元素 `x` 一来，
栈顶那些比 `x` 小的元素就再也不可能是别人的“下一个更大”了——它们的答案正是 `x`，弹出并记录。
每个下标进栈出栈各一次，O(n)。

## 模板：下一个更大元素（从左往右，栈中存待解决的下标）
```python
def next_greater(nums):
    n = len(nums)
    ans = [-1] * n
    st = []                          # 栈底到栈顶对应的值单调递减
    for i, x in enumerate(nums):
        while st and nums[st[-1]] < x:
            ans[st.pop()] = i        # x 就是栈顶元素的下一个更大
        st.append(i)
    return ans                       # 存的是下标；739 要的是 i - j
```

## 变体
- **循环数组（503）**：遍历 `2n` 次，用 `i % n` 取值，只在第一圈入栈。
- **左右边界（84）**：一个元素出栈时，新的栈顶就是它左边第一个更小的元素，当前 `i` 是右边第一个更小的元素，一趟就能算出以它为高的最大宽度。
- **接雨水（42）**：出栈元素是“坑底”，新栈顶和当前 `i` 是两侧的墙，按层累加。

## 易错点
- 栈里存**下标**，不要存值；值可以用下标取，宽度只能靠下标算。
- 严格小于还是小于等于，取决于有重复值时答案该归谁，写之前先想清楚。
- 84 末尾补一个高度为 0 的哨兵，让栈里剩下的元素都能出栈结算。
